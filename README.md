## 📦 五大核心功能模块

1. **M0 售后决策（仅退款博弈小票）**：基于贝叶斯网络动态核算抗辩赢面，量化五条处置路径期望成本，提供保利润/保评分决策滑块。
2. **M1 上架质检（SpecDiff 跨模态参数核验）**：在商品发布前交叉比对标题、属性表与详情页的核心参数，拦截冲突违规，提示模糊表述。
3. **M2 活动推演（活动穿底沙盘）**：暴力穷举凑单组合，提前发现引流品叠加满减导致的击穿毛利漏洞，并给出确定性防穿底策略。
4. **M3 直播合规（AdCompliance 话术熔断）**：开播前逐行扫描直播提词话术，标出高危医疗/功效与价格违规，触发红黄熔断灯并给出降敏改写。
5. **M4 评测报告（EvalForge 评测系统）**：基于 20 道金标衍生 200 道对抗与边界评测题，对三类解法提供准确率、期望成本与响应耗时三维评测。

## 🛠️ 技术架构与设计原则

- **技术栈**：Python 3.11 + Streamlit + SQLite
- **核心原则**：**80% 确定性代码 + 20% 大模型协作**。
  - 核心算账、概率推导、运筹穷举与规则匹配 100% 由纯确定性代码执行，坚决杜绝大模型算术幻觉；
  - 大模型（Qwen-Turbo / DeepSeek）仅用于非结构化人话翻译与话术改写，调用模式采用 `JSON Only`，`temperature = 0.1`。
- **合规与法条库**：RAG 仅用于精准索引广告法、价格法及电商平台质检规范的事实条文。
