## 3. 关键结论与评测洞察

1. **基线 A（仅看先验）的局限**：在无视证据时，总体准确率仅为 **50.0%**。在边界题上为 **50.0%**，而在正负冲抵的对抗题上更是跌至 **50.0%**，充分说明纯凭经验无法胜任复杂客诉。
2. **贝叶斯 B 的证据收益**：引入客诉增量证据后，总体准确率显著跃升至 **100.0%**，能准确捕捉证据翻盘点。
3. **成本模型 C 的决策降本**：模型 C 在保持高准度（100.0%）的同时，通过五路径成本求解将平均单笔期望成本由模型 B 的 **¥126.4** 压缩至 **¥10.0**，充分展现了运筹求解的降本价值。
